# Kiki 英语启蒙计划

这是一套面向 5 岁半儿童的家庭英语启蒙执行方案。计划强调稳定输入、亲子互动和低压力重复，不以背单词、默写或考试为目标。

当前已经完成第 1 个月的逐日细化。暑假期间，孩子周一至周四住在奶奶家：奶奶只按中文编号播放音视频并记录时长，家长通过晚间视频通话检查动作和理解；周五至周日由家长完成绘本共读和游戏互动。

## 从哪里开始

1. 先阅读[英语启蒙执行计划](./英语启蒙执行计划.md)，了解整体目标、执行原则和 12 周主题。
2. 进入[第 1 个月总览](./第1个月/第1个月总览.md)，准备绘本、歌曲和家庭材料。
3. 家长按[音视频准备清单](./第1个月/家长音视频准备清单.md)提前准备固定入口。
4. 奶奶周一至周四只使用[奶奶播放清单](./第1个月/奶奶播放清单.md)。
5. 家长按周计划完成视频检查、周末共读和记录。

## 启用 GitHub Pages

### 先确认私有仓库是否支持

- **个人 GitHub Free 账户**：Pages 只能从公开仓库发布。需要把本仓库改为公开，或者升级到 GitHub Pro。
- **GitHub Pro、Team 或 Enterprise**：可以直接从私有仓库发布 Pages。
- **普通个人账户发布后的网页仍然公开**：即使仓库保持私有，只要知道网址，任何人都能查看网页中的计划内容。只有 GitHub Enterprise Cloud 组织支持把项目 Pages 设置为仅仓库成员可见。

因此当前方案适合“仓库源码私有、英语计划网页公开”的情况。不要把孩子姓名、照片、联系方式或其他不希望公开的家庭信息写进用于 Pages 发布的 Markdown。

### 一次性发布设置

将本次文件提交并推送到 GitHub 后，在仓库中完成一次设置：

1. 打开 `https://github.com/wikyyuen/kiki-learn-english/settings/pages`。
2. 在 **Build and deployment** 下，将 **Source** 选择为 **Deploy from a branch**。
3. 将分支选择为 **main**，目录选择为 `/(root)`。
4. 点击 **Save**，等待 GitHub 的 `pages build and deployment` 完成。
5. 访问 <https://wikyyuen.github.io/kiki-learn-english/>；它会跳转到 <https://blog.wikyyuen.com/kiki-learn-english/>。

项目使用 Docsify 在浏览器中读取 Markdown，不需要安装 Node.js、Ruby、GitBook 或其他构建工具。`index.html` 已针对 `/kiki-learn-english/` 项目子路径进行配置。

## 本地预览

在仓库目录运行：

```bash
python3 -m http.server 8000
```

然后访问 <http://127.0.0.1:8000/>。本地预览只用于检查排版；正式地址由 GitHub Pages 提供。

## 内容维护约定

- 每个月保留一个总览文件，每周保留一个独立执行文件。
- 音视频使用“周次 + 序号 + 中文内容”的固定名称，避免长辈识别英文。
- 资源链接优先选择版权方或发布方页面，不推荐来源不明的下载站。
- 根据真实执行记录调整后续月份，不因漏做一天而补课或加量。
